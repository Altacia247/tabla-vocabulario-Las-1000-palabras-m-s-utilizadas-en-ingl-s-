Tu avance se guarda en este navegador y en este dispositivo. Para no perderlo (o para llevarlo a otro dispositivo), descarga una copia y cárgala cuando la necesites.

2. Cargar progreso

Elige un archivo .json que descargaste antes. Las palabras del archivo reemplazan a las que tengas con el mismo nombre; las demás no se tocan. Úsalo para recuperar tu avance o pasarlo a otro dispositivo.

¿Qué es un archivo .json?

Es un archivo de texto normal que guarda tus datos de forma ordenada. Puedes abrirlo con el Bloc de notas para verlo, pero no lo edites a mano: si cambias algo mal, la página no podrá leerlo. Descarga uno nuevo cada vez que termines de estudiar.

El autocompletado nunca borra lo que escribiste. Las casillas con fondo de color son sugerencias: revísalas, edítalas o pulsa Aceptar.
